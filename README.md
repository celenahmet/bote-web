# bote-web

Static source for `bote.web.tr`, prepared from the production web root for Vercel.

## Deployment

Import this repository into Vercel as an **Other** framework project. No build command is required and the repository root is the output directory.

The former `/blog` WordPress/PHP application is intentionally excluded. Production credentials, SSH material, logs, caches, dependency directories, and old backup archives are also excluded.
