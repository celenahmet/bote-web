📚 HTML Özet Alanı
HTML5 iskelet, semantik etiketler, listeler, tablolar, medya, formlar ve temel DOM kavramları.
HTML5 Temel İskelet zorunlu yapı 
<!DOCTYPE html>
<html lang="tr">
  <head>
    <meta charset="utf-8">
    <title>Başlık</title>
    <meta name="viewport" 
          content="width=device-width, initial-scale=1">
  </head>
  <body>
    Sayfa içeriği
  </body>
</html>
  • <!DOCTYPE html> → HTML5 olduğunu belirtir.
  • lang="tr" → dil bilgisini ayarlar.
  • meta charset="utf-8" → Türkçe karakterler için.
  • meta name="viewport" → mobil uyum için.
HTML5 Semantik Etiketler section / article / nav 
<header>Üst kısım</header>
<nav>Site menüsü</nav>
<article>
  <section>Makale bölümü</section>
</article>
<aside>Yan bilgi</aside>
<footer>Alt bilgi</footer>
  • <header> → sayfa / bölüm başlığı.
  • <nav> → gezinme menüsü.
  • <article> → bağımsız içerik (blog, haber).
  • <section> → mantıksal bölüm.
  • <footer> → telif, iletişim vb.
Listeler & Bağlantılar ol / ul / a 
<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<ol type="A">
  <li>Kahve</li>
  <li>Çay</li>
</ol>

<a href="https://huzem.hacettepe.edu.tr">
  HÜZEM
</a>
  • <ul> → sırasız liste (bullet).
  • <ol> → sıralı liste (1, A, I...).
  • <a> → href, mailto:, tel: ile kullanılabilir.
Tablolar tr / td / th 
<table border="1">
  <tr>
    <th>Kurs</th>
    <th>Öğrenci</th>
  </tr>
  <tr>
    <td>Web</td>
    <td>60</td>
  </tr>
</table>
  • <tr> satır, <td> hücre, <th> başlık.
  • colspan → sütun birleştirme.
  • rowspan → satır birleştirme.
Formlar & Gönderim Yöntemleri GET / POST 
<form action="/action_page.php" 
      method="post">
  <label for="email">E-posta</label>
  <input type="email" id="email" name="email">

  <label for="pass">Parola</label>
  <input type="password" id="pass" name="pass">

  <input type="submit" value="Gönder">
</form>
  • GET → adres çubuğunda görünür, cache’lenir, hassas veri için kullanılmaz.
  • POST → gövde üzerinden gider, URL’de görünmez, form için daha güvenli.
  • label for="id" → erişilebilirlik & tıklanabilirlik.
DOM Temelleri Node / Element / Attribute
  • Node → DOM içindeki her bir öğe (element, text, attribute...).
  • Element Node → HTML etiketinin kendisi (ör. <div>).
  • Text Node → etiket içindeki düz metin.
  • Parent / Child → ebeveyn & çocuk ilişki.
  • Attribute → etiket özellikleri (ör. src, href).
  • DOM Manipülasyonu → JavaScript ile HTML yapısını değiştirme.
🎨 CSS Özet Alanı
Temel seçiciler, kutu modeli, basit animasyon ve Bootstrap ile responsive yapı. (Flexbox dahil değil!)
Temel CSS Kuralı selector { } 
p {
  color: #e5e7eb;
  font-size: 14px;
}

.highlight {
  background-color: #7e57c2;
  color: white;
}

#ana-baslik {
  font-size: 32px;
}
  • Seçici türleri: etiket (p), sınıf (.class), id (#id).
  • Birden fazla özellik, ; ile ayrılır.
Kutu Modeli margin / border / padding 
.kutu {
  width: 200px;
  padding: 12px;    /* içerik ile kenar arası */
  border: 2px solid #7e57c2;
  margin: 10px auto; /* dış boşluk */
}
  • content → asıl içerik alanı.
  • padding → içerik ile border arası.
  • border → çerçeve.
  • margin → dış boşluk.
CSS Animasyon @keyframes 
@keyframes kutu1 {
  0%   { background-color: red; }
  50%  { background-color: yellow; }
  100% { background-color: green; }
}

.box {
  width: 100px;
  height: 100px;
  animation-name: kutu1;
  animation-duration: 4s;
  animation-iteration-count: infinite;
}
  • @keyframes ile zaman içindeki durumlar tanımlanır.
  • animation-duration → süresi.
  • animation-delay → başlangıç gecikmesi.
  • animation-iteration-count → tekrar sayısı / infinite.
Bootstrap Temeli CDN + grid 
<head>
  <meta name="viewport"
        content="width=device-width, initial-scale=1">
  <link rel="stylesheet"
    href="https://cdn.jsdelivr.net/npm/bootstrap@4.6.2/dist/css/bootstrap.min.css">
</head>

<div class="container">
  <div class="row">
    <div class="col-md-4">Sol</div>
    <div class="col-md-8">Sağ</div>
  </div>
</div>
  • container → ortalanmış, sabit genişlik.
  • row → satır.
  • col-sm-*, col-md-* → responsive kolonlar.
Bootstrap Card Yapısı card component 
<div class="card" style="width: 18rem;">
  <img class="card-img-top" src="..." alt="...">
  <div class="card-body">
    <h5 class="card-title">Başlık</h5>
    <p class="card-text">İçerik...</p>
    <a href="#" class="btn btn-primary">Tıkla</a>
  </div>
</div>
  • card, card-header, card-body, card-footer sınıflarıyla kart yapısı kurulabilir.
Bootstrap Tipografi & Renk .text-* / .bg-* 
<p class="text-primary">Mavi yazı</p>
<p class="text-white-50 bg-dark">
  Koyu arka planda yarı saydam beyaz
</p>

<button class="btn btn-success">Onay</button>
<button class="btn btn-danger">Sil</button>
  • .text-primary, .text-success, .text-danger
  • .bg-dark, .bg-light
  • .btn, .btn-primary, .btn-secondary, ...
⚙️ JavaScript Özet Alanı
Değişkenler, output yöntemleri, koşullar, döngüler, diziler, DOM ile etkileşim ve Canvas temeli.
JS Çıktı Yöntemleri innerHTML / console.log 
// 1) innerHTML
document.getElementById("metin").innerHTML = 
  "Merhaba JS!";

// 2) console.log
console.log("Debug mesajı");

// 3) alert
alert("Uyarı!");

// 4) document.write (genelde tavsiye edilmez)
document.write(5 + 6);
  • innerHTML → sayfadaki bir etikete yazı basar.
  • console.log → geliştirici konsoluna çıktı.
  • alert → popup uyarı.
Değişkenler & Veri Türleri var / let / const 
var isim = "Ahmet";
let yas = 21;
const okul = "Hacettepe";

let sayi = 3.14;      // Number
let aktif = true;     // Boolean
let liste = [1, 2, 3]; // Array
let ogrenci = { ad: "Ali", sinif: 3 }; // Object
  • var → eski, function scope.
  • let → block scope, modern kullanım.
  • const → değeri değişmez referans.
Koşullar & Ternary if / else / ? : 
let saat = 15;
let greeting;

if (saat < 10) {
  greeting = "Günaydın";
} else if (saat < 20) {
  greeting = "İyi günler";
} else {
  greeting = "İyi akşamlar";
}

// Ternary
let ehliyet = (yas < 18) ? "Alamaz" : "Alabilir";
  • if / else if / else → çoklu koşullar.
  • ternary → kısa if (?:).
Döngüler for / while 
for (let i = 0; i < 5; i++) {
  console.log("Sayı " + i);
}

const sehirler = ["ANKARA", "İSTANBUL", "İZMİR"];

for (let x of sehirler) {
  console.log(x);
}
  • for → klasik sayaç döngüsü.
  • for...of → dizi elemanları için idealdir.
DOM ile Etkileşim getElementById 
<p id="metin" 
   onmouseover="degistir()"
   onmouseout="geriAl()">
  Merhaba
</p>

<script>
function degistir() {
  document.getElementById("metin").innerHTML =
    "Yeni metin";
}

function geriAl() {
  document.getElementById("metin").innerHTML =
    "Merhaba";
}
</script>
  • onclick, onmouseover, onmouseout gibi event’ler etkileşim sağlar.
Canvas Temel Yapı 2D çizim 
<canvas id="can1" width="200" height="100"
        style="border:1px solid #000"></canvas>

<script>
  const c = document.getElementById("can1");
  const ctx = c.getContext("2d"); // 2D bağlam
  ctx.fillStyle = "#FF0000";
  ctx.fillRect(0, 0, 150, 75);
</script>
  • Canvas → piksel tabanlı çizim alanı, çizilen nesneler DOM’un normal elemanları gibi değildir.

Test Soruları (HTML / CSS / JS) Kendini yoklama
🔎 Her sorunun altında "Cevabı Göster" var.
Soru 1 (HTML)
Aşağıdaki etiketlerden hangisi HTML5 semantik etiketlerinden değildir?
A) <section>
B) <article>
C) <nav>
D) <center>
✅ Doğru cevap: D) <center> <center> eski (deprecated) bir etikettir, semantik HTML5 etiketi değildir.
Soru 2 (Formlar)
Hangisi GET methodu için doğrudur?
A) Gönderilen veriler adres çubuğunda görünmez.
B) Tarayıcı geçmişinde ve cache’te saklanabilir.
C) Hassas veriler için her zaman önerilir.
D) Bir HTTP metodu değildir.
✅ Doğru cevap: B) GET istekleri URL’de görünür, tarayıcı önbelleğine alınabilir ve geçmişte saklanır. Hassas veriler için tercih edilmez.
Soru 3 (CSS)
Aşağıdaki CSS özelliklerinden hangisi içerik ile border arasındaki boşluğu ayarlar?
A) margin
B) border
C) padding
D) outline
✅ Doğru cevap: C) padding Margin dış boşluk, padding iç boşluktur.
Soru 4 (Bootstrap)
Bootstrap’te col-md-4 sınıfı ne anlama gelir?
A) Orta ve üstü ekranlarda 12 kolonluk sistemde genişliği 4 kolon olan sütun.
B) Tüm ekran boyutlarında 4 piksel margin.
C) Sadece mobilde görünür.
D) Sütunun yüksekliğini belirler.
✅ Doğru cevap: A) col-md-4, orta (≥768px) ve üzeri ekranlarda 12’lik grid sisteminde 4 kolon genişliğinde sütun oluşturur.
Soru 5 (JavaScript değişken)
Aşağıdaki ifadelerden hangisi let ile ilgili doğrudur?
A) Function scope’tur, blok dışında da erişilebilir.
B) Block scope’tur, tanımlandığı süslü parantez dışında kullanılamaz.
C) Sadece sayısal değer alabilir.
D) Tarayıcı konsolunda kullanılamaz.
✅ Doğru cevap: B) let block scope’tur; tanımlandığı blok dışına sızması istenmez.
Soru 6 (JS Output)
Bir paragrafın içeriğini JavaScript ile değiştirmek için aşağıdaki kodlardan hangisi doğrudur? (id="p1")
A) document.p1.innerHTML = "Merhaba";
B) getElementById("p1") = "Merhaba";
C) document.getElementById("p1").innerHTML = "Merhaba";
D) innerHTML("p1") = "Merhaba";
✅ Doğru cevap: C) Doğru kullanım: document.getElementById("p1").innerHTML = "Merhaba";
Soru 7 (Canvas)
Canvas’ta 2D çizim bağlamını almak için hangi satır kullanılır?
A) const ctx = canvas.getContext("2d");
B) const ctx = getContext("2d");
C) const ctx = document.context("2d");
D) const ctx = "2d";
✅ Doğru cevap: A) Önce canvas elementi alınır, sonra getContext("2d") ile çizim bağlamı elde edilir.
Soru 8 (DOM kavramları)
Aşağıdakilerden hangisi Text Node tanımına en uygundur?
A) HTML etiketlerinin kendisi.
B) HTML etiketleri içindeki düz metin içeriği.
C) CSS kurallarını içeren node.
D) JavaScript kodlarını içeren node.
✅ Doğru cevap: B) Text Node, bir etiketin içindeki yazı kısmıdır.
